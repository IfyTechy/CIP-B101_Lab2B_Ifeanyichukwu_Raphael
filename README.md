# CIP-B101 Lab 2B — Advanced Linux CLI for Forensic Evidence Handling

**Module:** CIP-B101 (Cybersecurity Introduction Program) · **Lab:** 2B

## About this lab

Hands-on practice with the Linux command line as a forensic acquisition and handling tool, covering:

- **Stream redirection** — capturing command output (`>`, `>>`), redirecting stderr separately from stdout (`2>`), and piping between tools (`|`) to build evidence-processing pipelines
- **Safe file acquisition** — copying evidence with verification (hashing before and after transfer), avoiding metadata-altering operations on original evidence
- **Evidence handling discipline** — working on forensic copies, maintaining original evidence integrity, and documenting each handling step
